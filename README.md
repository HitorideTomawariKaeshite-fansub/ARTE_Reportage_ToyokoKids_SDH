# ARTE Reportage: Toyoko Kids (SDH Subtitles)

Japanese and Simplified Chinese/Japanese SDH subtitles for the ARTE Reportage documentary about Toyoko Kids.

## Subtitle files

- `ArteToyoko_ja.sdh_release_revision2.ass` — Japanese SDH subtitles (revision 2).
- `ArteToyoko_chs_ja.sdh_revision2.1.ass` — Simplified Chinese/Japanese bilingual SDH subtitles (revision 2.1).
