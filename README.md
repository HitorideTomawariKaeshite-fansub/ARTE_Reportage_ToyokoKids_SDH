## 简体中文

本仓库收录 ARTE Reportage 纪录片「被东京遗忘的一群人 ~新宿东宝大厦旁的孩子们~」的 SDH 字幕。

### 字幕文件

- `ArteToyoko_ja.sdh_release_revision2.ass`：日语 SDH 字幕（revision 2）。
- `ArteToyoko_ja.sdh_release_revision2.subset.ass`：日语 SDH 字幕的子集化版本（revision 2）。
- `ArteToyoko_chs_ja.sdh_revision2.1.ass`：简体中文／日语双语 SDH 字幕（revision 2.1）。
- `ArteToyoko_chs_ja.sdh_revision2.1.subset.ass`：双语 SDH 字幕的子集化版本（revision 2.1）。

子集化 ASS 文件已包含播放所需的字体子集，使用时无需另外加载第三方字体，可按原样播放。不推荐使用 PotPlayer 播放。
